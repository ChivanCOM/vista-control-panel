# Changelog

## 1.0.0 — 2026-11-24

First public release, split out of the BOONE distribution.

- Vista Control Panel: Category View with task links, category pages, Classic View, search,
  System page, Personalization hub.
- 19 native settings dialogs: AutoPlay, Desktop Background, Date and Time, Default Programs,
  Desktop Icon Settings, Display Settings, Folder Options, Keyboard, Mouse, Network and
  Sharing Center, Notification Area Icons, Power Options, Programs and Features, Regional
  and Language Options, Screen Saver, Sound, System Properties, User Accounts, Window Color
  and Appearance. Everything else opens the matching KDE settings module.
- Vista AutoPlay agent (opt-in), optional "Open settings" router for KDE.
- Distro-neutral: the system's name and logo come from /etc/os-release.
